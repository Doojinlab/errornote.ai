# errornote — 대시보드 확장 기능 스펙

> 로그인 후 대시보드 좌·우 영역에 두 개의 신규 기능을 추가한다.
> 이 문서는 Claude Code 작업용 요구사항 정의서다. 확정된 결정사항과
> 그 배경(왜)을 함께 담았다.

---

## 0. 배경 & 설계 원칙

### 0.1 제품 정체성

errornote는 **AI 기반 중국어 작문 오류 교정 PWA**다. 핵심 자산은
작문 오류 교정 엔진이며, 모든 신규 기능은 궁극적으로 이 엔진과
연결되어 **"오류 데이터 수집"이라는 한 우물로 수렴**해야 한다.

- 학생용 PWA: 4탭 구조 (학습 / 내 오류 / 도구 / 성장), Duolingo형 게이미피케이션
- 입력: 简体字·繁體字 모두 허용 / 출력: 简体字 전용

### 0.2 관통 설계 원칙 ★ (가장 중요)

> **errornote의 가능한 모든 기능은 정적으로 고정되지 않고,
> 학습자의 이용 데이터에 의해 방향이 자동으로 잡힌다.**

새 기능·화면을 만들 때마다 **"이건 어떤 사용자 데이터로 자동
조정되는가?"** 를 먼저 정의한다. 예:

| 기능 | 자동 조정 축 |
|------|------------|
| 今日热词 | 좋았어요/비추 → 콘텐츠 노출 수명 |
| 실전 HSK | 자주 틀리는 유형 → 해당 유형 출제 비중 |
| 내 오류 | 망각곡선·복습 성과 → 복습 타이밍·빈도 |
| 오늘의 학습 | 진도·정답률 → 다음 커리큘럼 난이도 |
| 관심분야 | 오래 머무는 카드 분야 → 관심사 암묵 학습 |

### 0.3 디자인 시스템 (기존)

| 토큰 | 값 | 용도 |
|------|-----|------|
| Hanji Ivory | `#FAF8F3` | 배경 |
| KR Blue | `#3B6FB6` | 한국어 UI 주색 |
| CN Red / Terracotta | `#D97757` | 중국어 콘텐츠·오류 마킹 **전용** (화면의 max 5%) |
| Jade Green | `#1D9E75` | 교정·성공 |

- 폰트: Pretendard(한국어), Noto Serif/Sans SC(중국어)
- **주의**: Terracotta는 중국어/오류 마킹에만. 두 신규 기능에서 남용 금지.

## 1. 기능 A — 실전 HSK (대시보드 좌측)

### 1.1 개요

HSK 시험 대비 실전 훈련. 실제 기출을 그대로 제공하지 않고,
**기출 유형 기반 AI 생성 문제를 무한 제공**한다.

> ⚠️ **저작권**: 실제 HSK 기출은 汉考国际(HANBAN) 저작권 대상.
> 절대 원문 기출을 그대로 저장·제공하지 않는다. 반드시 "기출 유형을
> 학습한 AI 생성 문제"만 사용. 카피 문구도 "기출 **유형** 무한 생성"으로.

### 1.2 입장 화면 — 선택 순서

**급수 → 영역 → 모드** 순 (인지적 자연 순서: 정체성→약점→오늘의 방식)

1. **급수**: HSK 3 / 4 / 5 / 6
   - 온보딩에서 목표 급수를 입력했다면 그 값을 **기본 선택**으로 미리 채움
2. **영역**: 독해 / 쓰기 / 말하기(추후 구현)
   - **쓰기 = 킬러 영역.** errornote 교정 엔진의 강점. 전면 배치·차별화 포인트.
   - 말하기: 회색 처리 + "곧 만나요" 뱃지. 클릭 시 **출시 알림 이메일 신청** 수집(수요 검증).
3. **모드**:
   - **문제 풀이 모드** (구 "빠르게 실력상승"): 실전처럼 계속 풀기
   - **개념 학습 모드** (구 "천천히 내실 다지기"): 틀린 유형을 이론과 함께
4. **입장하기** 버튼

### 1.3 오류 수집 연결 (필수)

- 문제 풀이 모드에서 **틀린 문항 → 자동으로 "내 오류" 탭에 적립**
- 개념 학습 모드는 그 적립된 오류를 유형별로 복습시키는 구조
- 자동 조정: 자주 틀리는 유형의 출제 비중을 자동 상향

## 2. 기능 B — 今日热词 (오늘의 핫워드, 대시보드 우측)

### 2.1 개요

교과서에 없는 **지금 살아있는 중국어**. 사용자가 관심분야를 고르면
그 분야의 요즘 뜨는 신조어·유행어를 **카드뉴스**로 매일 받는다.
"살아있는 중국어를 가져다주는 곳"이라는 차별화.

- 관심분야 예: 게임 / 연예 / 사회 / 경제 / 일상 / 밈
- 공급 방식: **완전 자동 파이프라인** (사람 개입 없음)

### 2.2 카드 구성

| 필드 | 내용 |
|------|------|
| 표현 (크게) | 예: `city不city` |
| 병음 + 직역 | 글자 그대로의 뜻 |
| 실제 의미/뉘앙스 | 진짜 쓰이는 느낌 |
| 예문 한 줄 | 실제 댓글·대화 맥락 |
| 유래 한 줄 | 어디서 왔나 (재미 포인트) |
| 격식도 태그 | 비격식/속어 · 시험 부적합 · 친구끼리만 등 |
| 출처·날짜 | 어느 플랫폼에서, 언제쯤 유행 |

- 카드 하단 **"이 표현으로 문장 만들기"** → 작문 → 교정 → 오류 적립(옵션)

### 2.3 완전 자동 파이프라인 (5단계)

**핵심 원칙: fail-closed — 확신 없으면 내보내지 않는다.**
사람(검수자)이 빠진 자리를 "게이트가 기본적으로 침묵"하는 것으로 대신한다.

```
1. 수집    관심분야별 web search (微博 热搜 / 小红书 / 抖音 / 知乎).
           넓게 많이 수집. 거르기는 다음 단계.

2. 실재 검증 (게이트 ①)  ★
           서로 다른 출처 2곳↑ + 최근 시점(예: 최근 2~3개월) 등장해야 통과.
           근거 약하면 폐기. AI 단독 "유행함" 생성 경로 차단.

3. 해설 생성
           통과 표현만 카드 필드 생성. 반드시 2단계 수집 출처에 근거.
           백지 자유 생성 금지(뜻 왜곡 방지).

4. 안전·격식 필터 (게이트 ②)
           비속어·성적 은어·정치 민감 표현 차단(중국 정치 은어 주의).
           애매한 것엔 격식도 태그 부착.

5. 큐레이션·배포
           기노출 중복 제거 → 신선도 정렬 → 분야별 풀 적재 →
           사용자 관심분야 개인화 배포.
```

### 2.4 피드백 루프 — "좋았어요!" / "비추!"

**철학: 억압적 감시(신고→삭제)가 아니라 긍정적 큐레이션.**
브랜드 톤에 맞는 귀여운 아이콘 버튼. "좋았어요"는 부담 없이 눌러서
피드백 데이터가 많이 쌓임 → 자동 조절이 정확해짐.

전략: 신조어는 무궁무진하므로 **대량 수집·공급**하고, 개별 카드의
**노출 시간을 유저 피드백으로 자동 조절**한다. 잘 맞는 건 오래 살고,
헛다리는 금방 내려가고, 빈자리는 대기 후보가 채운다.

#### 규칙 (원안 → 견고화)

원안:
- 좋았어요 10개↑ → 노출 기간 +1일
- 비추 10개↑ → 빠르게 다른 것으로 교체

**견고화 반영 (구현 시 이대로):**

1. **절대값이 아닌 비율로 판정** ★
   - 인기 분야(연예)는 좋았어요 100개도 쉽게, 비인기 분야(경제)는 며칠 걸림.
   - 절대값 10 → 인기 분야만 생존하는 편향.
   - **판정 = 본 사람 대비 좋았어요/비추 비율.**
   - "10개"는 **판정 최소 문턱(min sample)** 으로 사용: 최소 N명(예: 30명)
     노출 전에는 생존/교체 판정하지 않음.
   - 예시 로직:
     ```
     if impressions >= MIN_SAMPLE(=30):
         like_rate = likes / impressions
         dislike_rate = dislikes / impressions
         if like_rate >= LIKE_THRESHOLD:      노출기간 +1일
         if dislike_rate >= DISLIKE_THRESHOLD: 빠른 교체(동면 처리)
     ```
   - 원안의 "10개"는 like/dislike 카운트가 유의미해지는 최소 조건으로 유지.

2. **교체 = 삭제 아닌 동면(cooldown)** ★
   - 비추 누적으로 내려간 표현도 영구 삭제 금지 → **동면 풀**로 이동.
   - 이유: 유행어는 재유행하거나, "비추 = 별로"가 아니라 "이 사용자가 이미 아는 것"일 수 있음.
   - 냉각기 후 재등판 가능(특히 신규 유저 대상).

3. **조작 방어** ★
   - **1인 1표**: 계정당 카드당 좋았어요/비추 각 1회.
   - 비정상 연타·봇 패턴 무시.
   - 처음부터 넣을 것(후에 소급 어려움).

### 2.5 안전망 (완전 자동의 잔여 리스크 대응)

게이트가 촘촘해도 100%는 없다. "아무도 최종 확인 안 함"의 빈틈을
**사용자 집단이 자동 감시자** 역할로 메운다 → 위 비추 기반 자동 하강이
그 역할. 별도 상시 감시 인력 불필요.

## 3. 대시보드 전체 서사 (배치 의도)

```
        ┌────────── 가운데 ──────────┐
        │ 오늘의 목표 / 오늘의 학습   │   ← 정규 커리큘럼
        └───────────────────────────┘
┌── 좌 ──┐                      ┌── 우 ──┐
│실전 HSK│                      │今日热词 │
│진지·목표│                      │가볍·재미│
│ 시험대비│                      │ 트렌드  │
└────────┘                      └────────┘
     ↓                               ↓
     └────── 틀리면 → "내 오류" 자동 적립 ──────┘
```

- 세 진입점(정규·시험·습관)이 전부 오류 수집으로 수렴
- 무거운 카드(HSK)·가벼운 카드(热词)가 좌우 균형 → 대시보드 인상 개선
