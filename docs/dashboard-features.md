## ⚠️ 이름 혼동 주의 — 반드시 먼저 읽을 것

이 문서의 **今日热词(트렌드 신조어 카드뉴스)** 는 레포에 **이미 존재하는
"주간 카드뉴스"** 기능과 **완전히 다른 별개의 신규 기능**이다.

| 구분 | 기존 "주간 카드뉴스" (구현됨) | 신규 今日热词 (이 문서) |
|------|-------------------------------|----------------------|
| 성격 | 학습자 **개인 리포트** | **트렌드 콘텐츠** 피드 |
| 내용 | 4장 고정(통계·개선점·액션·다음 주) | 요즘 뜨는 중국 신조어·유행어 |
| 소스 | 학습자 본인 오류 데이터 | 웹(微博/小红书/抖音/知乎) 트렌드 |

**서로 대체·통합 대상이 아니다.** 今日热词 구현 시 기존 주간 카드뉴스 로직·테이블을 건드리지 말 것.

## 0. 배경 & 관통 원칙

errornote는 AI 중국어 작문 오류 교정 PWA. 핵심 자산은 교정 엔진이며,
**모든 신규 기능은 "작문 → 교정 → 오류 카드 → 내 오류" 한 우물로 수렴**한다.

### ★ 관통 설계 원칙 (가장 중요)
> errornote의 가능한 모든 기능은 정적으로 고정되지 않고,
> **학습자의 이용 데이터로 방향이 자동으로 잡힌다.**

| 기능 | 자동 조정 축 |
|------|------------|
| 今日热词 | 좋았어요/비추 → 콘텐츠 노출 수명 |
| 실전 HSK | 자주 틀리는 유형 → 해당 유형 출제 비중 |
| 내 오류 | 망각곡선·복습 성과 → 복습 타이밍·빈도 |

---

## ★ 공통 상호작용 모델 — 입장하기 → 기존 워크스페이스 재사용

**두 기능 모두 "입장하기" 클릭 시 새 화면을 만들지 않고, 기존 학습
워크스페이스(3분할: `문서 작성` + `오류 카드` + `AI 과외 채팅`)를 재사용한다.**
차이는 **채팅에 주입되는 시작 컨텍스트(시스템 프롬프트)뿐**이다.

```
[실전 HSK] 입장
  → AI 과외 채팅: 선택한 급수·영역·모드에 맞는 문제 제시
  → 사용자: 문서 작성에 답안 작성
  → [AI 분석] → 오류 카드 생성 → 내 오류 자동 적립

[今日热词] 입장
  → AI 과외 채팅: 오늘의 단어 + 한국어 의미·뉘앙스 제시 + "이 단어로 문장을 만들어보세요"
  → 사용자: 문서 작성에 그 단어로 작문
  → [AI 분석] → 오류 카드 생성 → 내 오류 자동 적립
```

구현 요점: 워크스페이스 진입 시 `mode`와 `context`를 파라미터로 받아
채팅 초기 메시지·시스템 프롬프트를 분기. 오류 카드·내 오류 파이프라인은 **기존 것 그대로 재사용**.

## 1. 기능 A — 실전 HSK (대시보드 좌측)

### 1.1 개요
HSK 시험 대비 실전 훈련. **기출 유형 기반 AI 생성 문제를 무한 제공**한다.

> ⚠️ **저작권**: 실제 HSK 기출은 汉考国际(HANBAN) 저작권 대상. 원문 기출을
> 그대로 저장·제공 금지. "기출 유형을 학습한 AI 생성 문제"만 사용.

### 1.2 입장 카드 — 보기 선택형 (칩)
사용자가 **칩(보기)에서 선택**한다. 선택 순서는 급수 → 영역 → 모드.

- **급수**: `HSK 3 / 4 / 5 / 6` — 단일 선택. 온보딩 목표 급수를 **기본 선택**으로 프리필.
- **영역**: `듣기(听力) / 독해 / 쓰기 / 말하기(곧)` — 단일 선택. (A-3: 듣기 신규 추가)
  - **쓰기 = 킬러 영역**(교정 엔진 강점). 기본 강조.
  - **말하기 = 비활성(disabled)**. 점선 처리 + "곧" 뱃지. 클릭 시 출시 알림 이메일 신청.
- **모드**: `문제 풀이 / 개념 학습` — 단일 선택.
  - 문제 풀이 → 하위 **연습 / 실전** (A-3).
    - 연습 → 하위 **채점 방식: 즉시 채점 / 모아서 채점**. (실전은 채점을 항상 "모아서"로 강제 — 시험 중 정답 미노출, A-5)
  - 개념 학습: 틀린 유형을 이론과 함께 (타이머·채점 제외)
- **입장하기**("우리 함께 고득점 노려볼까요!", A-2) → **전용 `/hsk/session` 라우트**로 모든 선택값
  (급수·영역·모드·연습/실전·채점방식) 전달(A-4). 세션이 영역별 시작 화면을 실제로 생성한다:
  듣기(오디오+MCQ)·독해(지문+MCQ)·쓰기(题目→작문 워크스페이스로 연결, 교정 파이프라인 재사용)·개념(설명 카드).
  - ※ A-α 스캐폴드: 단일 문항 생성·제시 + 스켈레톤 로딩. (§1.2 원래의 "워크스페이스 재사용"은
    쓰기에만 적용, 듣기/독해는 전용 세션.)
  - **A-β 듣기 오디오 컨트롤(구현)**: 재생/일시정지 · 속도 0.75/1.0/1.25x · 반복 1/2/무제한 ·
    스크립트 토글(원문+병음(성조색)+한국어 번역, 연습 모드만) · 오디오 사전생성·캐싱 · 실전은 1.0x·1회 잠금(A-5) ·
    모든 컨트롤 aria-label(A-11). TTS: 지문=ElevenLabs(`/api/hsk/tts`), 단어=브라우저(`lib/tts`).
    ※ 화자별 다른 음성(멀티보이스)은 추상화만 유지하고 후속 과제로 둔다.
  - **A-γ 다문항 세션(구현)**: 듣기·독해 문제풀이는 5문항 세트로 생성. 문항 네비 그리드 +
    표시(플래그)(A-10), 채점 타이밍 즉시/모아서(A-7), 성적표(점수·소요시간·틀린 문항 리뷰·재도전)(A-8).
    쓰기는 题目→작문 워크스페이스, 개념은 설명 카드(단일).
  - **A-δ 실전 모드(구현)**: 실전(exam)은 남은시간 카운트다운(문항당 듣기 45s/독해 40s) + 진행 바,
    마지막 15초 경고색(terra), 시간 초과 시 자동 제출(A-5). 오답은 즉시·모아서 모두 「오답 노트」
    (`/quiz-mistakes`, `quiz_mistakes` 테이블)로 자동 적립(A-8). 이탈 정책(A-9): 실전은 `beforeunload`
    경고 + "나가면 무효" 배너(결과 미기록), 연습(drill)은 localStorage 로 진행 저장 후 이어풀기.
    ※ "내 오류" 적립 대상 = 오답 노트(MCQ 스냅샷). 작문 오류카드(`/errors`)와는 별개 저장소.

### 1.3 자동 조정
- 문제 풀이 중 틀린 문항 → 내 오류 자동 적립
- 자주 틀리는 유형의 출제 비중을 자동 상향
- 개념 학습은 적립된 오류를 유형별로 복습

## 2. 기능 B — 今日热词 (대시보드 우측)

> ※ 상단 "이름 혼동 주의" 표 참조 — 기존 주간 카드뉴스와 별개.

### 2.1 개요
교과서에 없는 **지금 살아있는 중국어**. 관심분야를 고르면 요즘 뜨는
신조어·유행어를 카드로 매일 받는다. 공급은 **완전 자동 파이프라인**.

- 관심분야: 게임 / 연예 / 사회(시사) / 경제 / 일상(문화) / 밈 + **직접 입력**(관심 주제 텍스트)
  - 카드의 카테고리 칩을 누르면 선택기가 열림(B-1). UI 라벨(시사/경제/연예/문화/게임/밈)은
    기존 enum(society/economy/entertainment/daily/game/meme)에 리맵. "직접 입력"은 풀에 없으므로
    `/api/hotwords/custom` 로 **즉석 AI 생성**(풀 미저장).

### 2.2 카드 & 입장 흐름
- 카드에는 **오늘의 단어를 제시**(예: `city不city`). B-2 개편: 대문에 **한자 + 병음(성조부호,
  성조별 색상) + 한국어 뜻**을 함께 표기한다(트렌드 카드는 가볍고 재미 우선이라 뜻 즉시 공개).
  단어 옆 **스피커(발음 재생, 브라우저 TTS zh-CN) / 새로고침(같은 카테고리 다른 단어)** 아이콘 제공(B-4).
- **입장하기** → 워크스페이스 오픈 → AI가 한국어 의미·뉘앙스 제시 →
  "이 단어로 문장을 만들어보세요" → 사용자 작문 → 교정 → 오류 카드.
- 뜻은 **바로 알려주는 방식**으로 확정(트렌드 카드는 가볍고 재미가 우선).
  '추측 모드'는 추후 데이터 보고 옵션 추가 검토.

### 2.3 카드 필드(워크스페이스 내 AI 제시용)
표현 / 병음+직역 / 실제 의미·뉘앙스 / 예문 / 유래 / 격식도 태그 / 출처·날짜.

### 2.4 완전 자동 파이프라인 (5단계) — fail-closed
```
1. 수집    관심분야별 web search(微博 热搜/小红书/抖音/知乎). 넓게 수집.
2. 실재검증(게이트①) 서로 다른 출처 2곳↑ + 최근 2~3개월 등장해야 통과. 근거 약하면 폐기.
3. 해설생성 통과 표현만 카드 필드 생성. 반드시 수집 출처에 근거(백지 생성 금지).
4. 안전·격식필터(게이트②) 비속어/성적/정치민감 차단(중국 정치 은어 주의) + 격식도 태그.
5. 큐레이션·배포 중복 제거 → 신선도 정렬 → 분야별 풀 → 관심분야 개인화 배포.
```
**원칙: 확신 없으면 내보내지 않는다.** 사람 검수 자리를 게이트의 침묵이 대신.

### 2.5 피드백 루프 — "좋았어요!"/"비추!" (입장하기와 별개)
카드의 **좋았어요/비추는 자동 큐레이션(콘텐츠 수명 조절)용**이며,
입장하기(학습)와는 다른 목적으로 **공존**한다.

- 신조어를 대량 수집·공급하고, 각 카드의 노출 시간을 피드백으로 자동 조절.
- **비율로 판정**(절대값 아님):
  ```
  if impressions >= MIN_SAMPLE(=30):
      like_rate = likes / impressions
      dislike_rate = dislikes / impressions
      if like_rate >= LIKE_THRESHOLD:      노출기간 +1일
      if dislike_rate >= DISLIKE_THRESHOLD: 빠른 교체(동면 처리)
  ```
  - 원안의 "좋았어요/비추 10개"는 판정이 유의미해지는 **최소 문턱**으로 사용.
- **교체 = 삭제 아닌 동면(cooldown)**: 영구 삭제 금지, 냉각 후 재등판 가능.
- **조작 방어**: 1인 1표(계정×카드당 1회), 봇/연타 무시. 처음부터 넣을 것.
