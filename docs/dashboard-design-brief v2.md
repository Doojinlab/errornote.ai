# errornote 대시보드 입장 카드 — 디자인 브리프

> 목적: 로그인 대시보드에 좌·우 입장 카드(**실전 HSK**, **今日热词**)를 추가한다.
> 이 문서는 **시각 명세**다(색·타이포·컴포넌트·상태). 기능 로직은 `dashboard-features.md` 참조.
> Claude Design에서 1차 완성됨 — 이 문서는 그 최종 결과를 반영한 상태다.

---

## 1. 브랜드 & 톤

- 주 이용자: 한국 대학 중국어 전공 학부생. 세련되면서 활기 있게(딱딱한 관공서 톤 금지).
- 디자인 시스템:

| 토큰 | HEX | 용도 |
|------|-----|------|
| Hanji Ivory | `#FAF8F3` | 페이지 배경 |
| KR Blue | `#3B6FB6` / 진한 `#185FA5` / 딥 `#0C447C` / 연 `#E6F1FB` | 한국어 UI·HSK 카드 |
| CN Terracotta | `#D97757` / `#D85A30` / 딥 `#993C1D` / 연 `#FAECE7` | **중국어 텍스트·오류 마킹 전용(5% 이내)** |
| Jade Green | `#1D9E75` | 교정·성공·게이미피케이션 |

- 폰트: **Pretendard**(한국어), **Noto Serif SC**(중국어 표현·제목).
- ★ 철칙: 코랄은 **중국어 글자·테두리·텍스트에만**. 버튼·카드 배경 전체를 코랄로 채우지 말 것.

---

## 2. 시그니처 — "리본 카드"

```
┌─────────────────────────────┐
│ [아이콘] 타이틀      [뱃지]  │  ← 흰 타이틀 바
├═════════════════════════════┤  ← 3px 하드 룰 (카드 정체색)
│      색면 바디 (콘텐츠)       │
│      [ 입장하기 → ]          │
└─────────────────────────────┘
```
- 카드 외곽: `radius 12px`, `1px solid` 정체색, overflow hidden.
- 타이틀 바 하단 **3px 하드 룰**(얇은 헤어라인 금지 — 이 굵기가 정체성).
- 카드 바디·색면: **플랫**(그림자·그라데이션 없음).
- 예외: **입장하기 버튼만** 은은한 그라데이션 + hover lift 허용(아래 5번).

---

## 3. 카드 A — 실전 HSK

정체색 = KR Blue. 톤 = 진지·목표지향.
- 타이틀 바: 과녁 아이콘(`#185FA5`) + "실전 HSK"(`#0C447C`, 17px/500) + 뱃지 "AI 무한생성"(`#E6F1FB` 배경).
- 하드 룰 `3px #185FA5`. 색면 바디 `#E6F1FB`.
- **보기 선택 칩 3그룹**(라벨 10px `#185FA5`):
  - 급수 `3/4/5/6`, 영역 `독해/쓰기/말하기(곧)`, 모드 `문제 풀이/개념 학습`
  - 칩 상태: 선택 = `#185FA5` 채움/흰 글자 · 미선택 = 흰 배경/`1px #B5D4F4`/`#185FA5` 글자 · 비활성(말하기) = `1px dashed`/muted/"곧" 병기/클릭 시 알림 신청
  - 기본 선택: 급수 5 / 영역 쓰기 / 모드 문제 풀이

---

## 4. 카드 B — 今日热词

정체색 = Terracotta(중국어에만). 톤 = 가볍·재미.
- 타이틀 바: 불꽃 아이콘(`#D85A30`) + "今日热词"(**Noto Serif SC** `#993C1D`) + 뱃지 "연예".
- 하드 룰 `3px #D85A30`. 색면 바디 = **아이보리/화이트**(코랄 색면 금지).
- 단어 블록(흰 카드): 오늘의 단어 크게 — 예 `city不city`, **Noto Serif SC 26px `#D85A30`**. 아래 "입장하면 뜻풀이 · 문장 만들기". **뜻은 여기서 안 밝힘.**
- 좋았어요/비추 소형 버튼(자동 큐레이션용, 학습과 별개).

---

## 5. 입장하기 버튼 (양 카드 공통 사양)

- **흰색(밝은) 채움** + 카드 정체색 텍스트·테두리.
- 카드별 **은은한 색 그라데이션**: HSK = 흰→연파랑(`#E6F1FB`), 今日热词 = 흰→연코랄(`#FAECE7`). 코랄은 텍스트·테두리에만.
- **hover: 살짝 위로 봉긋 솟아오름**(translateY 위로 + 부드러운 그림자). 두 카드 다 파란 단색 채움은 금지(어색함).
- 풀폭, `radius 8px`, 14px/500, 우측 화살표.

---

## 6. 레이아웃 & 반응형

- **3열 통합**: 기존 대시보드 한 화면 안에 — **왼쪽=실전 HSK, 가운데=기존 대시보드(오늘의 목표·오늘의 학습·과제·동료 리뷰·바로가기 전부 유지), 오른쪽=今日热词.**
- ★ **가운데 UI를 절대 없애지 말 것.** 신규 카드는 좌우에 추가되는 것이지 중앙을 대체하지 않는다.
- 데스크톱: 좌(HSK+热词 세로 스택) / 우(넓은 중앙) 구성도 가능 — 스크린샷 참조.
- 모바일(<480px): 세로 스택, 순서 = 오늘의 목표 → 오늘의 학습 → 실전 HSK → 今日热词 → 나머지.
- 접근성: 칩·버튼 터치 타깃 44px↑, 비활성 말하기 칩 `aria-disabled`.

## 7. 하지 말 것
- 코랄/테라코타를 버튼·큰 색면·카드 배경에 채우기(중국어 글자·테두리·오류 마킹만).
- 카드 바디에 그림자·그라데이션(입장하기 버튼만 예외).
- 얇은 헤어라인만으로 카드 구분(3px 하드 룰 유지).
- 급수/영역/모드를 드롭다운으로(보이는 칩 선택 유지).
- 今日热词 카드에서 뜻 다 노출(입장 후 워크스페이스에서).
- 가운데 대시보드 UI 제거.
